# AI 规划参数

工作台采用「填写参数 → 生成提示词 → 查看与修改 → 复制」流程。应用只整理条件，不会调用外部 AI；外部 AI 输出的 JSON 仍通过导入预览、逐项修改后加入日历。

| 参数组 | 输入内容 |
| --- | --- |
| 身体与目标 | 身高、当前体重、年龄、目标体重、性别、活动量、健康目标 |
| 饮食 | 每日热量和蛋白质/碳水/脂肪、每日预算、餐数、用餐人数、做饭时长、三餐时间、器具与储存条件、偏好与禁忌 |
| 训练 | 每周次数、单次时长、组间休息、经验、场地与身体限制 |
| 作息 | 准备睡觉和起床时间、睡前准备时长 |
| 时间与补充 | 固定安排前后预留时间、重要事项提前提醒分钟数、其他要求 |

填写范围用于验证数据格式，不代表推荐值。数值可留空，未填写的营养和训练目标不会填成零；提示词要求 AI 先询问关键缺失条件，并说明不能同时满足的条件。时间使用 `HH:mm`，例如 `07:30`。

只显示所选模块的参数，综合计划包含全部模块。生成后的 `planningParameters` 按组列出条件，字段名带单位；每日营养目标按餐分配。量化参数优先于旧档案中的文字偏好。

默认附带库存、固定课程与组会。最近一周记录默认不附带，启用后可以分别选择体重、睡眠、饮食、训练和习惯。最终提示词依旧可手动删改。任何参数、模块、日期或历史选择变化都会暂停复制，重新生成后才恢复；重新生成会替换手动编辑的提示词。

生成时将计划数值和时间写入本地设置 `promptParameters`，随完整备份保存和恢复。身体与生活条件的修改只用于本轮提示词，下次打开从最新档案和体重记录带入；不会写入身体档案、作息目标或执行记录。未点击生成的临时输入不会保存。
