# 主题风格

「我的 → 主题风格」提供两种选择：

- **经典蓝白**（默认）：蓝色重点卡片、浅灰背景、白色面板、简洁品牌字母和原有饮食配图。
- **元气卡通**：粉色与奶白背景、粗黑描边、偏移阴影、小伙伴插画和卡通饮食配图。

风格通过本地设置 `appearance` 保存，并随完整备份导出、恢复。明暗模式继续使用独立的 `theme` 设置。没有 `appearance` 字段的旧备份和旧安装使用经典蓝白风格，不修改健康或日程数据。

两种风格共用输入框标签布局、按钮字号与点击区域、导航箭头、筛选标签排版、营养与身体指标排版，以及今日和日程页的时间线。切换只改变配色、装饰和图片，不撤销这些界面修复。

切换实施前的卡通版本已完整提交，并用 Git 标签 `theme-cartoon-v1` 保留，指向 `c7c3e95`。需要复核原始卡通外观时可查看该标签；当前版本已经内置切换功能，无需切换 Git 版本。
