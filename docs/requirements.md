# 已确认需求 · 2026-10-10

产品名：元气簿 / Vitalog。第一位用户是本人，目标平台 realme / Android 16，目标是减脂、改善作息、均衡饮食。

所有模块都纳入首版，深度顺序：饮食与菜谱 ≥ 训练 = 日历与提醒 > 习惯打卡 > 身体指标。

首页：美观、精简的仪表盘，以今日计划、下一项安排与菜谱为主。视觉采用撞色，不同模块不同颜色；食材图离线内置，可使用网络素材或 AI 配图。

身体档案：身高、体重、年龄、性别、目标体重；BMI、基础代谢和每日消耗估算、体重趋势与每周均值。生活条件包括器具、冷藏条件、饮食偏好、禁忌、预算、训练经验与场地，均由用户填写。

AI 流程：应用生成可编辑提示词 → 用户复制给外部 AI → 返回固定格式 → 粘贴或选择文件 → 校验 → 预览修改 → 确认导入。默认上下文包含档案、目标、生活条件、库存、课表和固定安排；最近一周记录可勾选。

饮食：AI 提供每餐热量、蛋白质、碳水与脂肪，允许修改，未知留空。区分计划与实际摄入。食材与用量、步骤、耗时、菜谱复用、库存、按计划需要量减库存生成购物清单。

饮食执行：按计划吃完时默认按实际用量扣库存；改吃其他餐食可修改，单餐可关闭扣库存。撤销或修正实际记录需要同步恢复/重新扣减，重复打卡不能重复消费。

训练：既能查看动作、组数、次数和要点、整次完成，也能逐组记录重量/次数，提供休息计时。计划由外部 AI 制定，应用负责展示、记录与执行。

日程：课程、组会、训练、饮食、作息与习惯在同一时间轴。支持调整时间与重复安排。未完成事项保留，手动调整，不自动顺延。

提醒：AI 建议等级，用户可改。课程/组会默认重要、提前 15 分钟通知；闹钟由用户选择。普通事项后台通知，安静事项只展示。每项可以修改提前时间与闹钟开关。

导入更新：默认替换对应日期和模块的未完成计划；已完成记录和课程/组会固定安排保留；预览标出替换内容和重叠时间；可选择追加。

睡眠：点「准备睡觉」「已起床」记录时间，支持事后补填。其他习惯由日程定义并打卡。

数据：本地保存，支持完整导出和恢复；外部 AI 由用户自行操作，首版不内置模型调用、账号或云同步。

验收：能建立档案、完成一轮提示词与导入、在日历执行饮食/训练/睡眠、核对库存和实际记录、导出并恢复，获得安卓安装包。锁屏与厂商后台行为另需真机验证。
