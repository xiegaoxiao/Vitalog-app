# 在 realme 上试用

1. 将 `output/Vitalog-0.1.0-arm64.apk` 发送到自己的手机，在文件管理器中打开并按系统提示安装。
2. 首次进入可填写个人档案，也可选择「体验示例」。示例会明确标识；正式使用前点「开始使用」清空示例，录入自己的信息。
3. 在「我的」填写目标、做饭与训练条件，在「饮食 → 食材库存」录入现有食材。课程可在 AI 工作台选择 `.ics` 文件导入。
4. 在 AI 工作台选择模块和日期，生成提示词；检查内容后复制给外部 AI，将返回的 JSON 粘贴回工作台，预览修改后确认。
5. 在「我的 → 提醒与权限」检查通知和「闹钟和提醒」权限，点击测试提醒。课程默认提前 15 分钟提醒，持续响铃闹钟由你自行开启。
6. 使用前后在「我的 → 备份与恢复」导出 JSON，并保存到自己选择的位置。

应用默认把记录保存在手机，备份也由你选择保存位置。当前安装包使用开发签名；后续升级应保持相同签名与包名，先备份，直接覆盖安装，避免卸载造成本机记录丢失。

网页预览仅用于体验界面：`http://localhost:8766/?demo=1`。它与手机记录互不影响，不提供安卓提醒。
