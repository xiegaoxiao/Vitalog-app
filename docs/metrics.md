# 指标来源与计算

BMI = 体重 kg / (身高 cm / 100)²。[CDC 公式说明](https://www.cdc.gov/bmi/faq/)。当前只显示数值，不给出诊断或自动训练强度建议。

基础代谢栏目使用 Mifflin–St Jeor 的静息能量消耗估算式：男 10w + 6.25h − 5a + 5；女 10w + 6.25h − 5a − 161。w 为 kg，h 为 cm，a 为周岁。18 岁以下不显示成人能量估算。[原始研究 PMID 2305711](https://pubmed.ncbi.nlm.nih.gov/2305711/)。这是一项估算，不是测量值，也不自动设置减脂热量目标。

每日消耗估算 = 上述估算 × 用户选择的活动系数（1.2 / 1.375 / 1.55 / 1.725）。系数作为可调整的经验输入，活动差异和个体误差会影响结果。

每周均重：截至所选日期的七个自然日，只对已录入的每日体重求算术平均。同日记录替换，不补造缺失日期，不纳入未来记录。

营养数值由外部 AI 输出、用户修改；应用只进行汇总。缺失值不会被当成零，一餐缺失某项时对应每日合计显示「—」。实际汇总只使用完成后的实际记录。
